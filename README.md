# Archetype Contracts

Solidity contracts for Scatter's NFT launchpad.

## Licensing

Creator-deployed implementations, logic libraries, interfaces, test helpers, and tests are available under the MIT License in `LICENSES/MIT.txt`.

Scatter-operated Batch, Payouts, and Factory contracts are available under the Business Source License 1.1 in `LICENSES/BUSL-1.1.txt`. Each Solidity file's SPDX identifier is authoritative. BUSL-1.1 versions change to the MIT License four years after publication.

## Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/guminc/archetype/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.
